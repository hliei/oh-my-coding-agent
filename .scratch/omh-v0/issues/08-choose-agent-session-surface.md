## Answer

### Public creation and state surface

The sole programmatic entry remains lazy `async def createAgentSession(options: CreateAgentSessionOptions | None = None) -> CreateAgentSessionResult`. It accepts neither mappings nor direct option keywords. `CreateAgentSessionOptions` is a frozen, slotted, keyword-only, identity-equality configuration record whose ticket-08-complete fields are `cwd: str | None = None`, `model: Model | None = None`, and `sessionId: str | None = None`; tickets 09 and 10 may add only their reserved trust/Extension/Tool fields. Validation and every effect begin on the factory coroutine's first await.

`CreateAgentSessionResult` is a factory-produced final read-only identity bundle whose current sole field is `session: AgentSession`; ticket 09 alone may add Extension results. `AgentSession` is a final, non-publicly-constructible and non-subclassable nominal owner handle. There is no `AgentSessionConfig`, mapping/builder form, bare-Session overload, public storage/resource/runtime dependency injection, or direct internal `Agent` escape.

One published Session exposes only lifetime-fixed `model: Model`, canonical `sessionId: str`, lifetime-fixed `systemPrompt: str`, immutable `messages: tuple[AgentMessage, ...]`, `isStreaming: bool`, `isIdle: bool`, `subscribe`, `prompt`, `abort`, `waitForIdle`, and inherited ticket-04 disposal/context-manager mechanics. Reads are synchronous, effect-free, and non-assignable. `messages` is the complete linear largest-confirmed-durable prefix. `isStreaming` and `isIdle` are not complements: cleanup/closing can make both false; successful disposal retains false/true plus the final read snapshot.

### Product Session identity, persistence, and recovery

A **Product Session** is necessarily durable, linear, bound to one normalized logical `cwd`, and identified by one non-reused canonical lowercase UUIDv7. `sessionId=None` always creates a new private-generator identity; an explicit `sessionId` is resume-only. It must be the standard 36-character lowercase hyphenated UUID form with version 7 and valid variant. Invalid syntax raises exact `ValueError("sessionId must be a canonical lowercase UUIDv7 string")` before lookup/effect. v0 has no recent-session selector, caller-chosen new id, ephemeral mode, public SessionManager/storage Adapter/config, branch, clone, or read-only copy.

On first factory await, `cwd=None` captures the process current directory; a relative string uses that same captured base. Empty, NUL, non-string, tilde/environment/file-URL expansion, `realpath`, symlink collapse, case folding, and Unicode normalization are not accepted transformations. Lexical absolute normalization removes dot segments and repeated separators, and the result must identify an existing directory before identity, Model/auth, store, or Prompt Resource work. That exact logical path enters the system prompt and Session Image and must match on recovery.

A **Session Image** authorizes recovery only at a settled boundary. Its semantic authority is exactly session id, normalized cwd, fixed Model provider/id, private contract version, complete linear AgentMessage history, and final settled marker. It never serializes Tools, Extensions, Prompt Resource bytes, effective system prompt, authentication, or live resources. Recovery validates the complete Image before those resources/effects, rebinds them from current admitted inputs, reconstructs the system prompt, and publishes an idle Session with value-equal history and no streaming/pending/error runtime state. It performs no migration, repair, truncation, skipped value, or rollback to an older boundary.

Canonical-id recovery has two closed failure classes. An absent, cross-cwd, incomplete/abandoned, corrupt, incompatible, or invariant-invalid Image raises exact `ValueError("sessionId does not identify a resumable Product Session for cwd")` without revealing which case. Persistence-substrate read failure raises `LifecycleError(code="cleanup", message="Product Session recovery failed", causes=(private_cause,))`. Neither case mutates state or creates a replacement. Stored Model identity is authoritative: omission rebinds its currently admitted nominal handle; an explicit Model must match. Authentication is rechecked, secrets are never stored, and missing `DEEPSEEK_API_KEY` rejects publication while leaving a prior Image resumable.

Exactly one live owner may hold a session id across processes sharing the persistence domain. Construction obtains a crash-released exclusive lease before Image read/commit or other resources and holds it across idle and closing until successful disposal/rollback. Contention raises exact `LifecycleError(code="busy", message="Product Session is already active")`; lease-substrate failure raises `LifecycleError(code="cleanup", message="Product Session ownership failed", causes=(private_cause,))`. There is no takeover, timeout, force unlock, or shared writer.

Construction fully initializes options, Image/recovery, Model/auth, trust, Prompt Resources, Tools, Extensions, and system prompt before one initial Image commit and public result delivery. Pre-commit failure mutates no store. Cancellation after a new Image commit but before delivery deletes it; failed deletion marks it incomplete/abandoned and preserves cancellation/original-error precedence. Resumed construction is read-only until a later Run, and its pre-delivery cancellation leaves the old Image resumable.

Each Run durably records admitted/unsettled state and its fixed expanded User Message before any Agent event or Model/Tool effect. Each finalized Message becomes durable before the public tuple/event. After Agent, Tool, listener, and cleanup settlement, `AgentSettled` and its listeners occur while streaming/non-idle; only then does the durable settled marker commit idle and wake prompt/idle observers. Crash before that marker leaves an incomplete, non-resumable Image rather than an older replayable boundary.

An admitted-record write failure raises `LifecycleError(code="cleanup", message="Product Session persistence failed", causes=(...))` before Run/state/event/effect and leaves the Session idle for caller retry. Any later persistence barrier failure cancels, forbids later effects, gives active prompt/idle observers the same failure, retains only confirmed durable Messages, and permanently enters closing. Disposal may only mark the id incomplete/abandoned and clean resources; it never recreates missing history or restores live reuse. There is no automatic storage retry, rollback, repair, import, or effect replay.

Successful `dispose()` retains the settled Image, releases resources and the exclusive lease, and permits later exact-id recovery. Active disposal first completes its abort and durable settlement. Cleanup failure retains ownership for retry. Settled Images do not automatically expire, compact, truncate, overwrite, or enter a public list/delete/archive/export/retention/GC surface.

### Prompt, Agent projection, and listeners

`AgentSession.prompt(text: str, options: PromptOptions | None = None) -> None` is one lazy Product Session barrier; empty text is valid. `PromptOptions` remains the frozen Public Value Record with sole `expandPromptTemplates: bool = True`. First await validates carriers, gives busy/closing/disposed admission precedence over resource-command errors, expands the fixed Prompt Resource snapshot, constructs one timestamped User Message, durably admits it, and drives the internal `Agent.prompt()` with the fixed Model/system prompt/Tools and complete history. It returns `None` after normal completion, Model error, recoverable Tool failure, or clean abort; caller-task cancellation settles the same abort before re-raising `CancelledError`. Lifecycle failures raise their owning carrier. Product Session exposes no `continue_()`.

`AgentSessionEvent` is the sealed-base/nested-record set `AgentStart`; `AgentEnd(messages, willRetry)` with `willRetry: Literal[False]`; `TurnStart`; `TurnEnd(message, toolResults)`; `MessageStart(message)`; `MessageUpdate(message, assistantMessageEvent)`; `MessageEnd(message)`; `ToolExecutionStart(toolCallId, toolName, args)`; `ToolExecutionUpdate(toolCallId, toolName, args, partialResult)`; `ToolExecutionEnd(toolCallId, toolName, result, isError)`; and fieldless `AgentSettled(type="agent_settled")`. Core events project after relevant durable-before-visible state reduction. `AgentEnd.messages` is the identical Run suffix, not complete history. Lifecycle failure may truncate without fabricated terminal events. Queue, retry, compaction, thinking/model-change, entry-appended, and session-info events are excluded.

`AgentSessionEventListener = Callable[[AgentSessionEvent], None | Awaitable[None]]`. Synchronous `subscribe()` rejects a non-callable, creates a strongly held independent ordered registration without replay, and returns an idempotent synchronous closure removing only that record. Busy registration is allowed; mutation affects only later fixed dispatch snapshots. A non-None/non-awaitable result becomes a listener failure cause. Closing/disposed rejects new registration; old closures become no-ops after disposal. There is no token/list, replay, priority/filter, parallel dispatch, or Session EventStream.

`waitForIdle() -> None` lazily captures only the current Run/disposal attempt, returns immediately when idle/disposed, and never waits for a later Run. It returns after the durable settled/idle boundary or raises the captured listener/cleanup/persistence/disposal failure; a persistence-failed closing Session re-raises its retained failure instead of hanging. `abort() -> None` lazily captures only the current Run, requests its existing signal, enforces the no-later-effect cutoff, and shares complete settlement across concurrent callers. It cannot rewrite a committed terminal class, does not affect a later Run, and leaves the Session reusable after clean abort. During disposal both methods join its attempt; after disposal both are immediate idempotent observers.

### Prompt Resources and fixed system prompt

A **Prompt Resource** is a passive Skill or file Prompt Template. After ticket-09 trust admits the normalized cwd, construction discovers only direct `.omh/skills/<name>/SKILL.md` and `.omh/prompts/<name>.md` entries. Untrusted/omitted trust performs no enumeration and yields an empty snapshot. Selected `.omh`, resource directories, and entries may not be symlinks. Discovery is name-sorted by Unicode code point. User-global resources, `.agents/skills`, ancestor search, legacy `.pi`, explicit paths, precedence, and public load/list/refresh/register APIs are excluded.

The entire selected set is read and validated atomically into one immutable per-construction snapshot. A Skill is BOM-free strict UTF-8 Markdown with exactly required string `name`/`description`, optional boolean `disable-model-invocation=False`, a matching 1–64-character lowercase-hyphen name, one-line nonempty description up to 1024 code points, and nonempty outer-trimmed body. A Template uses the same filename name grammar and exactly required one-line description plus optional one-line `argument-hint` up to 256 code points and a nonempty outer-trimmed body. Unknown fields, non-scalars, custom tags, anchors/aliases, and invalid bytes reject the complete Session construction. Body Unicode/line breaks are otherwise preserved without normalization. Skill and Template namespaces may share a name.

With expansion enabled, only first-character `/skill:<valid-name>` or `/<valid-name>` followed by end/whitespace enters a resource namespace. Missing/invalid Skill syntax raises exact `ValueError("Invalid Skill invocation")`; absent names raise `ValueError('Skill "<name>" was not found')` or `ValueError('Prompt Template "<name>" was not found')`. Other slash text remains literal. Expansion-disabled input is always literal. Rejection precedes Run/durable input/effect.

Skill expansion is exactly `<skill name="<name>" location=".omh/skills/<name>/SKILL.md">\nReferences are relative to .omh/skills/<name>.\n\n<body>\n</skill>`, with nonempty outer-trimmed arguments appended after two newlines unchanged. Template arguments use Reference-equivalent ECMAScript-whitespace quote splitting without escapes, then one nonrecursive pass for `$N`, `$@`, `$ARGUMENTS`, `${N:-default}`, `${@:N}`, and `${@:N:L}`, including Reference `N=0` behavior. No shell/environment/eval occurs. Only resulting User Message text is persisted.

One private deterministic builder emits six fixed sections: omh identity/core behavior; active ticket-10 Tool summaries; fixed file/verification/concise guidelines including the substantive named-check rule; model-invocable Skill descriptors and project-relative locations; creation date; normalized cwd. It builds once before publication, and `AgentSession.systemPrompt` plus every Model request remain identical for that instance. Recovery rebuilds once from current admitted resources. Prompt Templates, arbitrary context/AGENTS files, Reference identity/docs, credentials, user/global config, public setters, arbitrary append/replace, and mid-Session rebuild are absent. Ticket 09 may choose only one controlled contribution appended after the fixed six sections.

### Deliberate exclusions

Each explicit prompt expands once, drives exactly one Agent Run, and persists the exact complete suffix. v0 has no hidden compaction, summarization, context fitting/truncation, history dropping, branch/fork/clone/rewind/edit/merge, retry/backoff/reconnect/resume/effect replay, busy queue/steering/follow-up, autonomous Run, lifetime Model switch, system-prompt rebuild, Prompt Resource refresh, or Tool/Extension replacement. Provider context overflow persists through the ordinary Model-error path; only a later explicit prompt may continue.
