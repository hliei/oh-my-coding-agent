# Choose the values, schemas, and errors contract

Type: grilling
Status: resolved
Blocked by: 02, 03

## Question

How does v0 represent model and agent messages, content blocks, events, tools, usage, stop reasons, schemas, validation failures, exceptions, and serialized values so that Python callers receive one closed and testable contract?

## Comments

- 2026-08-18 — Accepted **Public Value Record** as the domain term for a passive, closed public record whose identity and lifecycle are not semantic. Each v0 Public Value Record is a frozen, slotted, keyword-only dataclass with the exact one-to-one public field spellings selected by this map. A tagged variant fixes its own discriminator; closed unions are type aliases over the nominal record variants, and finite string domains are `Literal` aliases so their runtime values remain strings. This decision freezes only the record shell: exact fields, nested container and opaque-JSON ownership, copying, validation, equality, and canonical serialization remain to be decided. It adds no builder, mapping-style access, serialization method, Pydantic dependency, or public root name. Factory-produced handles and owned resources (`Provider`, `Model`, streams, signals, `Agent`, and `AgentSession`), exceptions, callable interfaces, and mutable `AgentState` are not Public Value Records. The Reference Revision uses mutable structural objects and discriminated unions, so the eventual Ledger must record and verify this representation as `PA:frozen-public-value-records`; mutation of an already-created record is not a v0 comparison input.
- 2026-08-18 — Accepted recursively owned, read-only snapshots for every nested semantic container in a Public Value Record. At the first owning seam, omh recursively copies accepted sequences, mappings, and JSON subtrees; canonical record observations expose sequences as tuples and mappings through a read-only `Mapping`, retain no caller-owned mutable alias at any depth, and reuse the stable snapshot rather than copy-on-read. The same rule applies to an opaque JSON island after its allowed domain has been validated; its exact domain remains open. Concrete immutable-map libraries and serialization implementation remain implementation choices. Mutable lifecycle state such as `AgentState` is outside this rule and retains its owning ticket. This extends `PA:frozen-public-value-records`: Reference arrays and objects are mutable, although Reference Tool validation already clones `toolCall.arguments` before coercion and Agent assignment only shallow-copies its `tools` and `messages` arrays.
- 2026-08-18 — Accepted each Public Value Record constructor as the single runtime authority for its complete closed invariant. Construction validates the exact field set, runtime field types, fixed discriminator, closed union membership, and every nested semantic value before an instance exists; internal producers and decoders must use the same path, while operations receiving an existing instance may rely on that invariant rather than implement competing validators. Unknown fields, wrong types, invalid tags, and invalid nested values fail closed. The already accepted conversion of admitted sequence and mapping carriers into recursively owned read-only snapshots is representation normalization, not semantic coercion; no other string, numeric, boolean, null, enum, or object coercion occurs here. The exact failure carrier remains open. Tool-argument schema conversion and validation are a separate selected interface and remain open rather than inheriting this no-coercion rule. This construction-time validation extends `PA:frozen-public-value-records` because the Reference's ordinary TypeScript message and event interfaces have no uniform runtime constructor gate.

- 2026-08-19 — Accepted Reference-compatible conversion-before-validation for Tool arguments over the v0 Tool Schema Subset. ## Answer

v0 has one closed, constructor-validated value language. A **Public Value Record** is a frozen, slotted, keyword-only dataclass with the exact selected fields; tagged variants fix their own discriminator, closed unions are `TypeAlias` unions of nominal variants, and finite string domains are `Literal` aliases. Construction is the sole runtime invariant gate. It recursively owns admitted containers as tuples and read-only mappings, retains no mutable caller alias, and publishes no builders, mapping facades, codec methods, registries, or structural-subclass extension seams. Public Value Records use carrier-sensitive deep equality and hashing: concrete class participates, mappings ignore key order, tuples retain order, `1 != 1.0`, and positive and negative float zero differ. Hashes combine the concrete class with canonical bytes and are process-local.

Constructor carrier failures raise `TypeError`; admitted carriers that violate ranges or cross-field invariants raise `ValueError`. Validation fails at the first deterministic field/container path and every message begins `TypeName.path: `; the explanation after that prefix is noncontractual. Finite acyclic admitted structures have no hidden size or nesting limit and must be traversed without leaking Python's recursion limit. Resource exhaustion remains outside ordinary domain failures.

`JSONValue` is the sole public recursive JSON alias: null, bool, string, safe integer in `[-(2**53 - 1), 2**53 - 1]`, finite binary64 float including negative zero, tuple, or read-only string-keyed mapping. Boolean is never numeric; cycles, non-string keys, surrogate code points, nonfinite numbers, `Decimal`, bytes, enums, and arbitrary Python objects fail admission. `None` represents a missing optional field only where semantic null is excluded; the attribute remains readable and canonical encoding omits that member. Required JSON islands may contain explicit null.

The private canonical structure codec is shared by owning modules and always decodes through the expected public constructor or discriminator-selected closed union. It adds no envelope or implementation metadata. Canonical bytes are UTF-8 without BOM, whitespace, or newline; object keys sort by Unicode code point; Unicode is not normalized; escaping is minimal; safe integers use minimal decimal; and floats use the shortest round-trip float token, retaining `.0` and exact `-0.0`. Decoding rejects duplicate keys, invalid UTF-8, noncanonical spellings, unsafe integers, nonfinite numbers, unknown members, and invalid tags. Re-encoding accepted bytes is byte-identical. Public Values have no public serialization methods or functions, and executable handles/callables are not codec inputs.

Admission codes have none; listener/sink/cleanup/disposal codes require causes; `hook` is reserved unless the downstream hook group is selected. Real task cancellation remains `asyncio.CancelledError`, with cleanup failure chained beneath it. Core and Session consume but do not re-export these foundation errors.

Downstream `AgentEvent` and `AgentSessionEvent` use non-instantiable, externally sealed public bases with final nested Public Value Record variants. Their lifecycle tickets own exact nested names, fields, and ordering, but cannot replace this carrier. This is the sole exception to root-level event-union aliases and introduces no extra package-root names.
