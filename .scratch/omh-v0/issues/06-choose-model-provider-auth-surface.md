## Answer

v0 has exactly one Real Provider Adapter in addition to the deterministic local Faux Adapter. It is the Reference DeepSeek Adapter with Provider id `deepseek`, API dialect `openai-completions`, fixed base URL `https://api.deepseek.com`, and sole credential source `DEEPSEEK_API_KEY`. Its only public child path is `oh_my_llm.providers.deepseek`, whose zero-argument `deepseekProvider()` returns the closed factory-produced `Provider` handle installed through `MutableModels.setProvider()`. There is no generic Adapter-authoring seam, custom base URL/header/credential input, OAuth, stored login, interactive prompt, or fallback credential source.

The DeepSeek catalog is static and contains only one final read-only nominal `Model`: `deepseek-v4-flash`, named `DeepSeek V4 Flash`, with `api="openai-completions"` and `provider="deepseek"`. Those four fields are its only public observations. There is no remote discovery, refresh, alias, Pro model, public capability/pricing/context metadata, string selector, or in-session switching. `CreateAgentSessionOptions.model` is `Model | None`; omission deterministically selects this Model, while an explicit value must be the identical selected nominal handle. Invalid, Faux, foreign, fabricated, or unknown Models fail before authentication or effect. The chosen Model is lifetime-fixed on the created Session, and unresolved authentication rejects construction under the existing `ABD:reject-missing-model-at-session-creation` rule.

`createModels()` is zero-argument and returns an empty `MutableModels`. Lazy async `Models.getAuth(model)` re-reads the process environment on each first await and exposes only configuration state: configured DeepSeek returns frozen `AuthResult(source="DEEPSEEK_API_KEY")`, unconfigured DeepSeek returns `None`, and Faux returns `AuthResult(source=None)`. Actual secret bytes are resolved privately for each Provider effect, so rotation is visible and removal fails rather than using stale material. Secrets never enter results, events, exceptions, or logs.

The selected journey is text-and-Tool only and always non-thinking. Every DeepSeek request fixes `model="deepseek-v4-flash"`, `stream=true`, final usage inclusion, and `thinking={"type":"disabled"}`. Unexpected `reasoning_content` is a stream failure, never accepted or silently discarded. Images, reasoning levels/content/events, image generation, custom Tool choice, Provider extensions, cache controls, session affinity, custom transport fields, and public tokenizer/context-window admission are Surface Exclusions.

One private request constructor serves all four `Models.stream`, `complete`, `streamSimple`, and `completeSimple` paths and their Core/Session consumers. Tools are sent when present. `temperature=None` is omitted; otherwise the selected DeepSeek range is 0 through 2 inclusive and the value is passed unchanged. `maxTokens=None` is omitted; otherwise 1 through 384,000 inclusive is sent unchanged as `max_completion_tokens`. Provider-specific violations fail locally with `ModelsError(code="model_validation")` before network effect and are never clamped. Each activated operation can start at most one Provider request: Adapter, SDK/transport, Core, Agent, and Session perform no automatic retry, backoff, reconnect, or continuation. A caller may start a fresh Run only after complete settlement.

Valid terminal Usage maps `completion_tokens` to `output`, `prompt_cache_hit_tokens` to `cacheRead`, zero to `cacheWrite`, and `prompt_tokens - cacheRead` to `input`; optional `prompt_cache_miss_tokens` must equal that input. Provider `total_tokens` is preserved and must equal the four token categories. Streaming partials use all-zero Usage. Terminal counts that are missing, non-integer, negative, or contradictory fail with `ModelsError(code="stream")`; reasoning tokens are outside v0. Adapter-private fixed Flash rates are $0.14/M input, $0.28/M output, $0.0028/M cache read, and zero cache write. The unrounded `UsageCost.total` is the exact component sum. These versioned values are estimates, not invoices, and never silently track later Provider changes.

DeepSeek finish reasons map `stop` to `done("stop")`, `length` to `done("length")`, and `tool_calls` to `done("toolUse")`. `content_filter`, `insufficient_system_resource`, and unknown finish reasons map to `error("error")`; owner cancellation maps to `error("aborted")`. Missing credentials and HTTP 401/403 use private Models error code `auth`; other HTTP, 429/5xx, connection, and timeout failures use `provider`; malformed JSON/SSE, missing finish reason, invalid Tool delta, invalid Usage, and unexpected reasoning content use `stream`; local option admission uses `model_validation`. Pre-start failure emits only the terminal error. Post-start failure preserves accumulated legal response state before the error. Every helper exposes the same terminal error `AssistantMessage`, not a producer exception. Public error text is stable and redacted, while the concrete `ModelsError` remains private.

Release evidence has two layers. Deterministic fixtures cover the exact wire request, fragmented text/Tool streams, Usage/cost, finish/failure mapping, environment re-read, redaction, cancellation, zero retry, and post-failure reuse. A human-owned live gate using a real `DEEPSEEK_API_KEY` must additionally demonstrate a non-thinking streaming text Run, one Tool round trip, terminal Usage, cancellation followed by fresh success, and no secret disclosure. It is not ordinary key-bearing CI and retains only date, Provider/API/Model identity, procedure, and redacted outcome. Provider/account/credential unavailability blocks the real-Provider release claim; Faux cannot substitute.

Every other Reference Provider, API dialect, Model, authentication flow, retry layer, reasoning/image capability, and dynamic catalog feature is a v0 Surface Exclusion. The two actual behavioral differences introduced here are recorded below.

### Parity Ledger additions

All Reference evidence is pinned to `0e6909f050eeb15e8f6c05185511f3788357ddb3`.

#### `ABD:strict-deepseek-usage-finalization` — fail closed on invalid DeepSeek terminal Usage

1. **Scope**: DeepSeek terminal Usage projection through `Models.stream`, `complete`, `streamSimple`, and `completeSimple`, including their Core and Product Session consumers. Canonical terminal chunks vary missing, negative, non-integer, contradictory, cache-hit/miss, and raw-total fields. A/L/T/C are affected; E is not.
2. **Reference evidence**: `packages/ai/src/api/openai-completions.ts#L1117-L1152` replaces missing token fields with zero, clamps derived input at zero, accepts no Provider `total_tokens`, and recomputes `totalTokens`; `packages/ai/src/models.ts#L386-L405` calculates component costs and their sum from the resulting Usage.
3. **omh rule and reason**: valid terminal responses preserve Provider `total_tokens`, validate it against the selected token categories, validate optional cache-miss consistency, and calculate the same selected fixed-rate cost. Missing, non-integer, negative, or contradictory terminal Usage settles as `ModelsError(code="stream")`. This is an ABD because omh fails closed instead of publishing guessed, clamped, or recomputed observations.
4. **Comparator**: valid DeepSeek observations compare field-for-field after removing excluded reasoning and confirm the same cost arithmetic. Invalid fixtures deliberately compare Reference zero-fill/clamp/recomputation with omh's terminal stream error. Provider raw total is equal to omh `totalTokens` and must equal the category sum; it is not normalized away.
5. **Verification**: deterministic terminal-SSE rows cover every required/optional field, hit/miss consistency, raw-total equality and contradiction, absent/fractional/negative values, all-zero partials, exact unrounded component costs, terminal event/result agreement, no secret/raw-body disclosure, and fresh-Run reuse after failure.
6. **Authority**: [Choose the model, provider, and authentication surface](06-choose-model-provider-auth-surface.md).

#### `ABD:deepseek-request-preflight` — reject out-of-range DeepSeek options before network effect

1. **Scope**: selected DeepSeek `StreamOptions` admission for all four `Models` methods and their Core/Product Session consumers. Canonical inputs exercise `temperature` around 0 and 2 and `maxTokens` around 1 and 384,000. A/E are affected; L/T/C are not.
2. **Reference evidence**: `packages/ai/src/api/openai-completions.ts#L546-L586` copies every defined temperature and every truthy max-token value into the streaming request without enforcing the selected DeepSeek ranges, leaving later client/Provider handling to occur after Adapter admission.
3. **omh rule and reason**: the selected DeepSeek Adapter accepts only temperature 0 through 2 inclusive and max tokens 1 through 384,000 inclusive, passing valid values unchanged and rejecting a violation with `ModelsError(code="model_validation")` before any network effect. Local deterministic admission prevents Provider-dependent failure timing and accidental paid requests.
4. **Comparator**: in-range values produce the same request fields. For an out-of-range value, compare Reference progression into its client/Provider request path with omh's local typed rejection and empty network-effect trace; do not compare Provider wording.
5. **Verification**: boundary and just-outside rows for both fields across all four methods, including omission for `None`, unchanged valid wire values, exact error code, a network spy proving zero calls, no clamping, no retry, and later successful Session reuse.
6. **Authority**: [Choose the model, provider, and authentication surface](06-choose-model-provider-auth-surface.md).
