## Answer

### Distribution and import seams

v0 publishes one installable and versioned `omh` Distribution. It installs the `omh` command and three separately importable and callable Public Import Packages: `oh_my_llm`, `oh_my_core`, and `oh_my_coding_agent`. They are not separately installable or separately versioned. This packaging scope is neither an ABD nor a Parity Ledger entry, and co-installation neither authorizes cross-layer public re-exports nor collapses the three public seams.

The Public Import Surface is a closed allowlist. `oh_my_core` and `oh_my_coding_agent` have root-only public import paths. `oh_my_llm` has its root plus only the concrete Provider child paths later selected by [Choose the model, provider, and authentication surface](06-choose-model-provider-auth-surface.md). Installed or technically importable implementation modules are not public. `compat`, `node`, `rpc_entry`, Harness, proxy, and cross-layer re-exports are excluded.

Retained Reference names remain one-to-one unless an accepted Ledger record says otherwise. v0 adds no PEP 8 aliases.

### `oh_my_llm`

`oh_my_llm` is centered on an explicit collection, never a package-global registry:

- Root names: `createModels`, `Models`, `MutableModels`, `Provider`, and `Model`.
- `Models` methods: `getProviders`, `getProvider`, `getModels`, `getModel`, `getAuth`, `stream`, `complete`, `streamSimple`, and `completeSimple`.
- `MutableModels` adds only `setProvider`; Provider catalogs are static in v0.
- `Provider` is a factory-produced nominal handle whose public surface is read-only `id` and `name`, plus use as the value accepted and returned by the collection. It is not a public Adapter-authoring seam.
- No package-level `registerProvider`, `getModel`, `stream`, or `complete` convenience functions exist.

The root text/Tool/stream name allowlist is `Context`, `Message`, `UserMessage`, `AssistantMessage`, `ToolResultMessage`, `TextContent`, `ToolCall`, `Tool`, `Usage`, `StopReason`, `StreamOptions`, `SimpleStreamOptions`, `AssistantMessageEvent`, `EventStream`, `AssistantMessageEventStream`, `AbortSignal`, `validateToolCall`, and `validateToolArguments`. `AbortSignal` is the sole ticket-04 addition to this allowlist. It is a factory-produced read-only observer exposing only monotonic `aborted` and lazy async `wait()`; cancelling a wait never aborts the owning operation, and normal settlement does not mark the retained signal aborted. Public request options stop at `StreamOptions`; `SimpleStreamOptions` has no reasoning, and `AssistantMessageEvent` has no `thinking_*` members. `createAssistantMessageEventStream`, API-specific option types, thinking/image names, and cost/retry/overflow/JSON-repair helpers are excluded.

`StreamOptions` and `SimpleStreamOptions` contain no caller-supplied `signal`; direct callers cancel through the owned `EventStream` or their awaiting task. v0 publishes no `AbortController` or other external cancellation-source type.

The minimal public Faux seam is:

- `fauxProvider`, `FauxProviderHandle`, `FauxResponseFactory`, `FauxResponseStep`, `fauxAssistantMessage`, `fauxText`, and `fauxToolCall`;
- handle members `provider`, `models`, `getModel`, `state.callCount`, `setResponses`, `appendResponses`, and `getPendingResponseCount`;
- no public options on `fauxProvider()`;
- text and `toolCall` content only, while `fauxAssistantMessage` retains `stopReason` and `errorMessage`.

Faux uses the public `Models` seam and cannot replace real-Provider release evidence. `fauxThinking`, `createFauxCore`, custom catalogs/options, `handle.api`, and registration lifecycle are Surface Exclusions.

The remaining `oh_my_llm` surface has one owner per decision: [Choose the async, stream, and cancellation contract](04-choose-async-stream-cancellation-contract.md) defines stream and cancellation mechanics and adds only `AbortSignal`; [Choose the values, schemas, and errors contract](05-choose-values-schemas-errors-contract.md) alone owns `ModelsError`/`ModelsErrorCode`, schema-construction names, and closed Python value/event/error/schema representations; [Choose the model, provider, and authentication surface](06-choose-model-provider-auth-surface.md) alone owns whether `getAuth` returns public `AuthResult`, `createModels` options/auth injection, and real-Provider child paths, factories, and factory configuration. It may not add API-specific request-option types. No other ticket may expand the root allowlist.

Steering/follow-up APIs, `QueueMode`, `ThinkingLevel`, `CustomAgentMessages`, `AgentToolCall`, turn-update/prepare/stop contexts, and before/after Tool hook groups are initially excluded. [Choose the Agent loop and Tool lifecycle](07-choose-agent-loop-tool-lifecycle.md) may add a before/after Tool hook only as a complete field-and-type group if it selects that public hook; otherwise it may not expand these configurations or root names. Direct dependency assembly, `AgentSessionConfig`, service/runtime factories, `AgentSessionRuntime`, importable `main`/`parseArgs`, RPC entry, advanced run-mode entries, state escape, model switching/cycling, thinking, queues, compaction, retry, branching, export, and bash shortcuts are excluded. Tickets 04/05/08 own resource mechanics, value shapes, and Session lifecycle/persistence; tickets 09/10/11 exclusively own later Extension, Tool, and run-mode additions.

### `PA:python-illegal-identifier` — Python-illegal `Agent.continue` spelling

1. **Scope**: Agent continuation method naming. The named public interfaces are Reference `Agent.continue()` and omh `oh_my_core.Agent.continue_()`. Canonical input selects the continuation member on the corresponding Agent. A/L/T/E/C: `none`; this record authorizes only a member-name mapping and owns no continuation behaviour.
2. **Reference evidence**: fixed Reference Revision `0e6909f050eeb15e8f6c05185511f3788357ddb3`; `packages/agent/src/index.ts#L1-L4` exports `Agent` from the package root, and `packages/agent/src/agent.ts#L347-L375` defines public `async continue(): Promise<void>`. Python syntax cannot express the corresponding call as `agent.continue()` because `continue` is a reserved keyword.
3. **omh rule and reason**: the sole public spelling is `Agent.continue_()`, classified as a Python Adaptation because Python cannot express the Reference member selector. omh exposes no dynamic `continue` attribute, `getattr(agent, "continue")` compatibility entry, snake_case alternative, or other alias. This record authorizes no other rename. Async representation belongs to ticket 04 and continuation behaviour to ticket 07; assistant-tail continuation that depends on excluded steering/follow-up queues is not a v0 comparison input. This is a pure naming PA, not an ABD.
4. **Comparator**: normalize only omh member selector `continue_` to Reference selector `continue` when comparing the public name. Do not normalize any other class, method, parameter, field, or event name. Any continuation behaviour comparison after that name normalization is owned entirely by ticket 07, not by this PA.
5. **Verification**: installed-distribution import of `oh_my_core.Agent`; assert `continue_` is callable; assert there is no public dynamic attribute `"continue"`; and assert Python syntax rejects `agent.continue()`.
6. **Authority**: [Choose the public Python interface](03-choose-public-python-interface.md).
